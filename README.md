# Data Science

A structured learning repository covering the foundations of **Data Science, Machine Learning, Deep Learning, Reinforcement Learning, data analysis, visualization, mathematics, Python, NumPy, Pandas, SQL, and practical experimentation**.

The repository combines notes, Jupyter notebooks, datasets, algorithms, assignments, and hands-on experiments to build an end-to-end understanding of the data-science workflow.

## 📚 What This Repository Covers

| Area | Topics / Work Covered |
|---|---|
| Python | Python fundamentals and programming practice |
| NumPy | Numerical computing, arrays, and core operations |
| Pandas | Data loading, cleaning, transformation, analysis, and CSV/JSON data |
| SQL | SQL queries, database operations, and transactions |
| Data Collection | API calls, web scraping, and data collection fundamentals |
| Data Visualization | Matplotlib, Seaborn, exploratory visualizations, and plotting |
| Mathematics | Calculus, probability, and probability distributions |
| Supervised Learning | k-NN, Linear Regression, Lasso Regression, Logistic Regression, Naive Bayes, Decision Trees, SVMs, and ensemble methods |
| Unsupervised Learning | K-Means, DBSCAN, Hierarchical Clustering, PCA, and anomaly detection |
| Deep Learning | ANN, CNN, RNN, NLP, Transformers, RAG, and model training |
| Reinforcement Learning | Q-Learning and SARSA |
| Applied Work | Classification, regression, clustering, NLP, and deep-learning experiments |

## 🚀 Getting Started

### Prerequisites

Recommended setup:

- Python 3.10+
- pip
- Jupyter Notebook or JupyterLab

### Clone the Repository

```bash
git clone https://github.com/aryannair005/Data-Science.git
cd Data-Science
```

### Install Common Dependencies

```bash
pip install numpy pandas matplotlib seaborn scikit-learn jupyter
```

For Deep Learning or Transformer notebooks, install the additional libraries required by the individual notebook, such as PyTorch and Transformers.

### Start Jupyter

```bash
jupyter notebook
```

Then open the notebook for the topic you want to study.
